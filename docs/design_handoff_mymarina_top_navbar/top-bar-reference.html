Resize this window to see the bar collapse

Below 760px the secondary nav items move into a "My account" dropdown and the avatar name hides. Below 500px the wordmark and the notifications icon drop off too. Click the avatar or the "My account" button to see the menus open.

The bar uses CSS container queries (not media queries) so it can be embedded in narrower regions — a side-panel app shell, a print preview — and still collapse correctly.
